# AI Development Workflow — MANDATORY

> **RULE #1: Every user message MUST be translated before any code is written.**

## Workflow (applies to EVERY message, no exceptions)

```
USER MESSAGE → TRANSLATE → WAIT FOR APPROVAL → IMPLEMENT → VERIFY → USER DECISION
```

### Step 1: TRANSLATE

Before writing ANY code, convert the user's message into this format and show it:

```
## TASK
[One-sentence summary]

## IMPLEMENTATION PLAN
### Backend (if applicable)
1. [Step with file path]

### Frontend (if applicable)
1. [Step with file path]

## FILES AFFECTED
- Modified: [files]
- Created: [files]

## VERIFICATION STEPS
1. [How to verify]
```

### Step 2: WAIT FOR APPROVAL

Do NOT proceed until the user says "yes", "approved", "go", or similar.

### Step 3: IMPLEMENT

Search the codebase before writing. Follow existing patterns. Check for errors after each change.
See `.ai/agents/coder.md` for rules.

### Step 4: VERIFY

Run browser tests. If tests fail, debug (max 3 retries).
See `.ai/agents/tester.md` and `.ai/agents/debugger.md`.

### Step 5: USER DECISION

Present:
- **[✅ Next]** — User confirms → task complete
- **[🔍 Reinvestigate]** — Deeper analysis → return to step 4

## Critical Rules

- NEVER skip the translation step
- NEVER start coding before approval
- NEVER stop before presenting the final verification step
- Search before creating — this is a migration, not greenfield
- All UI strings must use i18n (`t('key')`) — no hardcoded text
- See `.github/copilot-instructions.md` for full project context
