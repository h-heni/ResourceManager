ENVIRONMENT FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Development Branch (dev)
   │
   ├─ Push → CI runs (build + test) → No Docker push
   │
   ▼
Staging Branch (staging)
   │
   ├─ Push → CI runs (build + test + Docker push) → staging images
   ├─ Manual deploy → Staging VPS
   ├─ QA Testing
   │
   ▼
Production Branch (main)
   │
   ├─ Push → CI runs (build + test + Docker push) → latest images
   ├─ Manual deploy → Production VPS (requires approval)
   └─ Live in production
